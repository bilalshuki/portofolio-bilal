Tentang Saya

Siswa Kelas 11 RPL 1 di SMKN 6 Tangerang Selatan

Halo Semuanya! Nama saya Bilal Shaki Try, saya adalah siswa kelas 11 RPL 1 di SMK Negeri 6 Tangerang Selatan. Saya memiliki minat yang besar dalam dunia teknologi dan pemrograman tau. Saat ini, saya sedang fokus mempelajari dasar-dasar koding untuk membangun pondasi yang kuat sebagai seorang calon Software Developer agar bisa bekerja di bidang yang saya minati.

Meskipun masih berstatus pemula, saya aktif mengeksplorasi beberapa bahasa pemrograman seperti HTML & CSS untuk dasar pembuatan website, Python & C# untuk melatih logika dan algoritma dasar, serta Kotlin untuk pengenalan aplikasi Android. Saya sudah mulai membuat beberapa projek latihan kecil dan terus semangat untuk belajar hal-hal baru di dunia RPL.
